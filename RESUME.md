# Resume-ready project entry

## Canvas Coursework Assistant | PowerShell, Canvas REST API, Windows DPAPI, JSON

- Built a read-only Canvas LMS integration that answers natural-language questions about assignments, deadlines, readings, modules, and announcements using live course data.
- Designed a local credential bridge with Windows user-scoped encryption, strict API route allowlisting, HTTPS host validation, request expiration, and cross-host pagination protection.
- Implemented a file-based request/response workflow with no listening network port, keeping API tokens out of prompts, logs, and source control.

## One-line version

Built a secure PowerShell bridge between an AI assistant and the Canvas REST API, enabling on-demand coursework queries while keeping credentials encrypted and local.
